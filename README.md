## Project Description

Quiz Game with High Score is a simple console-based quiz game developed using Python. The program contains 10 multiple-choice questions about basic computer programming concepts.

Players answer each question by entering A, B, C, or D. The program automatically checks their answers, calculates their scores and percentages, and displays their results.

The game also tracks the highest score achieved during the current session and allows players to play again.

## Project Objectives

- Create an interactive multiple-choice quiz using Python.
- Automatically check answers and calculate scores.
- Display the player's final score and percentage.
- Track the highest score during the current session.
- Apply basic Python programming concepts.

## Features

- 10 multiple-choice questions
- Player name input
- Automatic answer checking
- Score and percentage calculation
- High-score tracking
- Input validation
- Play Again option
- Performance feedback

## Technologies Used

- Python
- Python IDLE
- Console-based interface

## How to Run the Program

1. Install Python on your computer.
2. Download `Quiz_Game_with_High_Score.py` from this repository.
3. Open the file using Python IDLE.
4. Press **F5** or select **Run → Run Module**.
5. Enter your name and answer the questions.
6. View your score and choose whether to play again.

## Limitations

The high score is stored temporarily while the program is running. It resets when the program is closed.

The current version uses a console-based interface instead of a graphical interface.
